# tools/

Utilitários de **desenvolvimento** do LineBR Legacy (build, deploy, verificação, automação).

> Não confundir com:
> - `source/aCis_datapack/tools/` — instaladores de banco que fazem parte da aCis.
> - `runtime-reference/tools/` — instaladores do pack original preservado.

## Conteúdo previsto (à medida que o projeto evolui)

- Scripts de build/empacotamento (JDK 21 + Ant).
- Scripts de deploy para a VPS.
- Verificadores de integridade (comparar jar compilado vs `runtime-reference/`).
- Automação de aplicação de diffs de revisão (410/411).

Vazio na fase atual — reservado pela estrutura profissional do repositório.
