## Por que "comunidade acima de conveniência"

O Lineage II é um **jogo social disfarçado de RPG**. O conteúdo acaba; as pessoas não. O end game do L2 não é um boss — são **outros jogadores**.

Consequências práticas desta regra:

| Decisão | Como respeita a regra |
|---------|----------------------|
| **Economia 1x** | mantém a interdependência: ninguém é autossuficiente |
| **Craft 100% + Spoil 1x** | o Dwarf continua sendo necessário para todos |
| **Teleport Retail** | encontros casuais no mundo continuam existindo |
| **Learning manual + Guild Masters** | o jogador circula, vai à cidade, encontra gente |
| **Quests obrigatórias** | ninguém pula o caminho comum |
| **Hero visível (Skin)** | o topo é admirado publicamente |
| **Sem Auto Farm** | quem está no spot é uma pessoa, não um script |

## Tensões registradas

### NPC Buffer gratuito
✅ Aprovado (até level 🔴 **PENDENTE**).
⚠️ O [SOCIAL_PHILOSOPHY §1](../design/SOCIAL_PHILOSOPHY.md) alerta: buffer NPC enfraquece a classe de suporte e a interdependência. **O level definido é a mitigação** — buffer no early game (quando não há suporte disponível) sem substituir o Buffer humano no mid/end game. Quanto **mais alto** o level, maior o impacto sobre o jogo social. Decisão do Owner → [OPEN_DECISIONS](OPEN_DECISIONS.md).

### Auto Loot (VIP Gold)
✅ Aprovado. ⚠️ Reduz a presença ativa no loot, mas **não** substitui o esforço de matar. A exclusão de Raid/Boss/Eventos preserva a disputa nos momentos de maior valor social.

### Marketplace
✅ Aprovado, **em Giran**. ⚠️ Comércio remoto reduz interação presencial; a ancoragem em Giran é a mitigação.

## Regra de admissão
Qualquer proposta futura que **facilite o jogo solo** ou **reduza a necessidade do outro** deve ser avaliada contra esta regra — e, por padrão, recusada.
