# PvP e PvE — LineBR Legacy

> ✅ Decisões aprovadas pelo Owner.

---

## Regra geral

> **Tudo retail.** Nenhuma custom de combate, dano, skill, karma ou PvP é aprovada ([CUSTOM_SYSTEMS](CUSTOM_SYSTEMS.md)).

## PvP

| Elemento | Regra |
|----------|-------|
| **PvP** | ✅ **Importante** — retail |
| **PK** | ✅ **Importante** — retail |
| **Karma** | Retail |
| **Drop por PK** | Retail |
| **Consequência de morte** | Retail (perda de XP) |

> **PvP com consequência** é o que dá peso ao conflito. Sem risco, PvP vira esporte sem aposta.

## PvE

| Elemento | Regra |
|----------|-------|
| **Raid Boss** | ✅ **Importante** — retail |
| **Grand Boss** | ✅ **Importante** — retail |
| **Auto Loot em Raid/Boss** | ❌ **NÃO funciona** (nem para VIP Gold) |
| **Drop de Boss** | ❌ **Auto Loot NÃO funciona** |
| **Eventos** | ❌ **Auto Loot NÃO funciona** |
| Drop / Spoil | **1x** ([ECONOMY](ECONOMY.md)) |

> **Decisão de destaque:** excluir Raid/Boss/Eventos do Auto Loot preserva a **disputa** exatamente onde o valor é maior. É o que impede o Auto Loot de virar vantagem competitiva nos momentos decisivos.

## Endgame competitivo

| Sistema | Regra |
|---------|-------|
| **Castle Siege** | ✅ **Importante** — retail |
| **Olympiad** | ✅ **Importante** — retail |
| **Hero** | ✅ **Importante** — retail + [Hero Dynasty Skin](CUSTOM_SYSTEMS.md) (só aparência) |
| **Seven Signs** | ✅ **Importante** — retail |

### Integridade do topo
- ❌ **Nada comprável influencia Olympiad, Siege ou Hero.**
- A Hero Dynasty Skin é **exclusivamente cosmética** — sem atributos, status, defesa, ataque ou bônus. Ela **marca** o Hero; não o fortalece.
- O Hero é conquistado **jogando** (Princípio Final).
