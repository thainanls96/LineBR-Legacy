# Architecture Decision Records (ADR)

Este diretório registra, de forma permanente e datada, **toda decisão arquitetural** do LineBR Legacy. Um ADR nunca é apagado: quando uma decisão muda, cria-se um novo ADR que **supersede** o anterior (e o antigo é marcado como `Superseded`).

## Formato

Cada ADR segue a estrutura:

- **Status** — `Proposto` · `Aceito` · `Superseded por ADR-XXX` · `Deprecated`
- **Contexto** — o problema/situação que motivou a decisão
- **Decisão** — o que foi decidido
- **Consequências** — implicações positivas e negativas
- **Alternativas consideradas** — quando relevante
