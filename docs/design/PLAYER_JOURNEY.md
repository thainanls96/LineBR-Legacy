# Jornada do Jogador — LineBR Legacy

> Do level 1 ao Hero. **O que o jogador deve sentir em cada fase**, e por quê.
> ⚠️ **Nível de evidência:** as descrições do Interlude abaixo vêm de **conhecimento geral**, não de fonte verificada. Pela nossa própria metodologia, isso é **★☆☆☆☆–★★☆☆☆**. Nenhum número/local aqui é fato até ser validado ([EVIDENCE_REGISTER](../knowledge/baseline/EVIDENCE_REGISTER.md)). Este documento é **intenção de experiência**, não referência técnica.
> ⚠️ **Depende de [D-001 (rates)](DECISION_LOG.md)** — em x1 a jornada abaixo é de meses; em mid-rate, de semanas. É outro jogo.

---

## Fase 1 · Level 1–20 — "O mundo é grande e eu sou pequeno"
| | |
|---|---|
| **Objetivo** | Aprender o jogo; escolher classe (1ª profissão ~20) |
| **Mapa** | Vila inicial da raça (Talking Island, Elven, Dark Elven, Orc, Dwarven) + arredores |
| **Equipamentos** | No-grade → D-grade; quests de novato dão o primeiro set |
| **Economia** | Quase nula — jogador é consumidor puro; adena mal cobre potions |
| **Quests** | Newbie quests (essenciais: guiam e equipam) |
| **Bosses** | Nenhum relevante |
| **Progressão** | Rápida por design (é o tutorial do mundo) |
| **Motivação** | **Curiosidade.** Descobrir. A 1ª profissão é o primeiro "marco de identidade" |

## Fase 2 · Level 20–40 — "Preciso de gente"
| | |
|---|---|
| **Objetivo** | Sair da tutela; encontrar party e clã |
| **Mapa** | Gludio, Dion, arredores; primeiras dungeons |
| **Equipamentos** | D → C-grade (aqui o **craft** entra na vida do jogador) |
| **Economia** | Começa a existir: compra de shots, primeiros materiais, primeiro contato com Dwarf |
| **Quests** | Quests de C-grade, materiais, adena inicial |
| **Bosses** | Primeiros raids acessíveis em grupo |
| **Progressão** | Desacelera — o primeiro "muro" real |
| **Motivação** | **Pertencimento.** Aqui o jogador ou encontra um grupo ou desiste. É a fase crítica de retenção |

## Fase 3 · Level 40–52 — "O jogo começa de verdade"
| | |
|---|---|
| **Objetivo** | 2ª profissão (~40) — a maior conquista da vida média do jogador |
| **Mapa** | Giran (hub econômico), Cruma Tower, Dion/Oren |
| **Equipamentos** | C → B-grade; enchant entra em cena |
| **Economia** | **Auge da participação**: craft, spoil, mercado de Giran, comércio real |
| **Quests** | Quest de 2ª profissão (marco); quests de material |
| **Bosses** | Raids de médio nível; loot cobiçado |
| **Progressão** | Lenta e social — party se torna obrigatória na prática |
| **Motivação** | **Orgulho + cobiça.** A classe finalmente "é" a classe |

## Fase 4 · Level 52–61 — "O muro"
| | |
|---|---|
| **Objetivo** | Atravessar a faixa mais dura do jogo |
| **Mapa** | Dragon Valley, Cruma, catacumbas/necrópoles (Seven Signs) |
| **Equipamentos** | B-grade sólido; A-grade é sonho |
| **Economia** | Consumo pesado de shots; jogador vira **produtor** (spoil/craft) ou depende do mercado |
| **Quests** | Seven Signs entra como motor de progressão e política |
| **Bosses** | Raids relevantes; clãs organizados dominam |
| **Progressão** | 🔴 **A fase onde servidores perdem gente** — em x1 é brutal |
| **Motivação** | **Superação.** Quem passa daqui está comprometido com o servidor |

## Fase 5 · Level 61–75 — "A elite se forma"
| | |
|---|---|
| **Objetivo** | Consolidar-se; clã forte; A-grade |
| **Mapa** | Aden, Oren, TOI, Forge of the Gods, Imperial Tomb, Pagan |
| **Equipamentos** | A-grade; enchant sério; itens de boss |
| **Economia** | Concentração de riqueza; mercado de topo; **inflação aparece aqui se algo está errado** |
| **Quests** | Subclass (~75) — marco; noblesse na sequência |
| **Bosses** | Grand Bosses; competição entre clãs |
| **Progressão** | Muito lenta; medida em semanas/meses |
| **Motivação** | **Status e política.** O jogo vira geopolítica de clãs |

## Fase 6 · Level 75–80 — "O topo"
| | |
|---|---|
| **Objetivo** | Noblesse; subclasses; preparar Olympiad |
| **Mapa** | Rune, Goddard, Hot Springs, Wall of Argos, Forge of the Gods |
| **Equipamentos** | A/S-grade; enchant alto; itens raros |
| **Economia** | Elite; poucos itens, preços absurdos; **aqui a economia é testada** |
| **Quests** | Noblesse (marco), quests de subclass |
| **Bosses** | Grand Bosses / epics — eventos do servidor |
| **Progressão** | Assintótica |
| **Motivação** | **Reconhecimento.** Ser conhecido no servidor |

## Fase 7 · Olympiad → Hero
| | |
|---|---|
| **Objetivo** | Provar-se; virar Hero |
| **Requisito** | Noblesse |
| **Economia** | Indireta, mas define o valor de itens de PvP |
| **Progressão** | Cíclica (por período de Olympiad) |
| **Motivação** | **Admiração** ([P-07](../constitution/DESIGN_PRINCIPLES.md)). Hero é escasso por design — se muitos são, ninguém é |

## Fase 8 · End Game — "O mundo é nosso"
| | |
|---|---|
| **Objetivo** | Siege, castelo, domínio territorial, epics |
| **Mapa** | Castelos, epic bosses |
| **Economia** | Taxas de castelo; economia coletiva de clã |
| **Motivação** | **Poder coletivo.** O único conteúdo verdadeiramente infinito do L2: **outros jogadores** |

## A leitura transversal
O Interlude tem uma curva **deliberadamente cruel**: rápida no início (fisga), brutal no meio (filtra), assintótica no fim (retém pelos vínculos sociais, não pelo conteúdo).

**O end game do L2 não é conteúdo — são pessoas.** Por isso [P-06](../constitution/DESIGN_PRINCIPLES.md) (party) e a [SOCIAL_PHILOSOPHY](SOCIAL_PHILOSOPHY.md) importam mais que qualquer boss: quem chega ao fim fica pelo clã, pela rivalidade e pelo status — não pelo próximo item.
